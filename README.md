# 🔑 Store Keysbot

نظام متكامل لبيع المفاتيح والحسابات عبر موقع ويب وبوت تلجرام مع إدارة نقاط المستخدمين والمحافظ.

## ✨ المميزات الرئيسية

- **موقع ويب احترافي**: واجهة مستخدم حديثة وسهلة الاستخدام
- **بوت تلجرام متكامل**: شراء وإدارة المفاتيح مباشرة من التلجرام
- **نظام النقاط**: إدارة نقاط المستخدمين والمحافظ
- **نسخ احتياطية تلقائية**: حفظ البيانات تلقائياً على Hugging Face
- **مفاتيح عشوائية**: توليد أسماء وكلمات مرور عشوائية لكل مفتاح
- **إدارة الأخطاء**: إرجاع النقاط عند فشل العملية

## 🚀 البدء السريع

### المتطلبات

- حساب Hugging Face مع توكن (HF_TOKEN)
- توكن بوت التلجرام

### الإعدادات

1. **إضافة HF_TOKEN**: أضف متغير البيئة `HF_TOKEN` في إعدادات الـ Space
2. **إضافة BOT_TOKEN**: أضف متغير البيئة `BOT_TOKEN` في إعدادات الـ Space
3. **تحديث الرابط**: تأكد من تحديث رابط الموقع في ملف البوت

## 🔧 المنافذ

- **3000**: الموقع الرئيسي
- **5000**: API السيرفر
- **7860**: منفذ Hugging Face الافتراضي

## 💾 النسخ الاحتياطية

يتم حفظ النسخة الاحتياطية تلقائياً كل ساعة إلى:
- **Repository**: `AlliFF/Store-Keysbot-Data`
- **الملف**: `store_keysbot_backup.zip`

## 🐛 استكشاف الأخطاء

### الموقع لا يعمل
- تحقق من السجلات: `/tmp/website_server.log`
- تأكد من تثبيت المكتبات: `pnpm install`

### البوت لا يستجيب
- تحقق من السجلات: `/tmp/bot.log`
- تأكد من صحة `BOT_TOKEN`
- تأكد من أن رابط الموقع محدّث في البوت

### فقدان البيانات
- تحقق من وجود `HF_TOKEN` في الإعدادات
- تأكد من أن Dataset `AlliFF/Store-Keysbot-Data` موجود وخاص

## 📞 الدعم

للمزيد من المساعدة، تواصل مع المطور عبر التلجرام.
